# 結果表の見やすさ改善 実装計画

1. `test-results-page.mjs` に、並び順の文言・構造化パラメータ・7列テーブル・復元ボタンのアサーションを先に追加し、テストが失敗することを確認する。
2. `results-page.mjs` に、並び順の文言と構造化された商品パラメータを生成する純関数を新設する。
3. 結果行・表ヘッダー・ツールバー・内蔵スクリプトを更新：行ごとの確認日時を削除し、現在の並び順を表示し、出力順の復元をサポートする。
4. 列幅・レスポンシブ非表示・並び順状態コントロールの CSS を更新する。
5. 完全なテストと構文チェックを実行し、`results.html` を生成して、実ブラウザで並び替え・復元・検索/フィルター互換性・7列レイアウトを検証する。
6. 既存のバックグラウンド監視プロセスを再起動し、以後の生成ページが新しいテンプレートを使うようにしてから変更をコミットする。
