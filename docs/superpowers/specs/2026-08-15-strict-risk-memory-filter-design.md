# 厳格なメモリ・リスクフィルター 設計

## 目的

検索収集・通知・結果ページから、購入要件を満たさない2種類の商品を完全に除外する。タイトルに16GBのみが明記され32GBへ増設可能なだけの商品、および外観・画面・深刻な故障・ロックのリスクがある商品。

## フィルタールール

- タイトルに `32GB` が明記されていれば保持。
- タイトルに `16GB×2`・`16GBx2`・`16GB*2`・`16GB+16GB` が明記されていれば合計32GBとして保持。
- タイトルに `16GB` のみ明記されている場合は、詳細または判定理由で32GBと検出されても除外。
- タイトルが「増設可・拡張可・最大32GB対応」などの能力を示しても、現在のスペックが16GBなら除外。
- 判定理由に「外观或屏幕有缺陷」を含む場合は除外。
- 判定理由に「严重故障/锁机风险」を含む場合は除外。

## 実装方法

`laptop-filters.mjs` の中央ハードフィルターチェーンで、タイトルのメモリ矛盾とリスク理由を一元的に判定します。新規検索結果は書き込み前に拒否し、既存結果は結果ページ生成時に掃除します。通知ロジックも同じフィルター結果を使うため、フロントエンドの非表示とバックグラウンド通知ルールがずれません。

タイトルメモリ判定は純関数にカプセル化し、新結果の評価と既存結果のフィルターの両方で共用します。リスク判定は既存の構造化 `reasons` に基づき、依存やバックグラウンドプロセスは追加しません。

## テスト

- `16GB` 単独で詳細は32GB判定：拒否。
- `16GB` で32GBへ増設可能と明記：拒否。
- `16GB×2`・`16GB+16GB`・明確な `32GB`：保持。
- 「外观或屏幕有缺陷」：拒否。
- 「严重故障/锁机风险」：拒否。
- 正常な32GBビジネスノート：引き続き通過。

## 運用制約

既存の Windows/PowerShell 実行方式・単一のバックグラウンド監視プロセス・10分のチェック周期を維持し、依存や常駐タスクを追加しない。
